# Sources officielles consultées

Toutes consultées le **1er novembre 2026**. Les recherches générales n'ont servi qu'à repérer les dates de révision ; elles ont ensuite été vérifiées sur les pages Apple.

| Source | Lien | Ce qui en a été tiré |
|---|---|---|
| App Store Review Guidelines (révision du 16 octobre 2026) | https://developer.apple.com/app-store/review/guidelines/ | 1.5, 1.6, 2.1, 2.3.x (dont le texte exact de 2.3.3 et 2.3.4), 2.5.x, 4.1, 4.2, 5.1.1, 5.1.2, 5.2.x (texte exact de 5.2.3), 5.6.1 |
| Upcoming requirements | https://developer.apple.com/news/upcoming-requirements/ | Xcode 26 / SDK iOS 26 (28 avril 2026), cible iOS 13+ (9 septembre 2026), questionnaire d'âge (31 janvier 2026), Required Reason APIs (1er mai 2024), DSA (2024-2025) |
| App privacy details | https://developer.apple.com/app-store/app-privacy-details/ | Définition de « collect », traitement sur l'appareil, partenaires tiers, critères facultatifs |
| Age ratings values and definitions | https://developer.apple.com/help/app-store-connect/reference/app-information/age-ratings-values-and-definitions | Catégories 2026, définitions exactes (accès web, contenu généré, alcool, santé, publicité, messagerie), paliers 4+ / 9+ / 13+ / 16+ / 18+ |
| Screenshot specifications | https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications | Tailles iPhone et iPad, 1 à 10 captures, formats, pas de canal alpha |

| Describing use of required reason API | https://developer.apple.com/documentation/bundleresources/describing-use-of-required-reason-api | Catégories et codes (contenu de la page non rendu par l'outil : codes vérifiés d'après la documentation connue et les manifestes des SDK Expo) |

Limites : deux pages de documentation Apple (Required Reason API, chiffrement) n'ont pas pu être lues en entier par l'outil. Les règles correspondantes sont appliquées selon la pratique documentée, et marquées comme telles.
